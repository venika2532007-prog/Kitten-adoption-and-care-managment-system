# 🐱 Kitten Adoption & Care Management System

A database management system designed for a kitten rescue shelter to manage kitten records, adoption requests, vaccinations, and daily care activities efficiently.

---

## 📌 Project Overview

The **Kitten Adoption & Care Management System** is built to help animal shelters maintain organized records of kittens, adopters, staff, vaccinations, and adoption workflows.

The system provides:
- Kitten profile management
- Adoption request tracking
- Vaccination record maintenance
- Staff care activity monitoring
- Relational database management using MySQL

This project demonstrates concepts of:
- ER Modeling
- Relational Schema Design
- Database Normalization
- SQL Queries
- Foreign Keys & Relationships

---

## 🚀 Features

### 🐾 Kitten Management
- Store kitten details
- Manage breed information
- Track health status and personality
- Upload kitten photos

### 👨‍👩‍👧 Adoption Management
- Maintain adopter details
- Handle adoption requests
- Approve or reject requests

### 💉 Vaccination & Care Tracking
- Record vaccination history
- Store medical information
- Track daily care activities by staff

### 🗄️ Database Management
- Fully normalized relational database
- Multiple interconnected tables
- Foreign key relationships
